# Parity evidence sources

Figure 2 from Andrew Mack, Kraig Yuheng Tou, Mark Henry, Zhengxun Wu and Lauren Greenspan, *Scaling Interpretable Transformers with Parity Bottleneck Layers*, [arXiv:2607.20652v1](https://arxiv.org/abs/2607.20652v1). Licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as linked by the arXiv abstract and HTML on 17 November 2026.

`circuit-edit-success-figure2.pdf` is the complete standalone original vector figure from the authors’ TeX source archive, member `fine_grained_controllability.pdf`. The PNG is its 2,400-pixel rendering. No crop, relabeling or alteration of plotted data, axes or legend was made. This presentation maps the image’s white background to its paper color. The embedded “ours” in the legend refers to the paper’s authors.

The source archive supplies this plot, but no underlying numerical circuit-edit dataset or plotting script. This presentation therefore displays the original graph and does not infer precise values from its pixels. A full-size source viewer preserves access to all five methods, all three tasks and all three edit budgets.

Appendix C defines success by comparing the target recipient with the unchanged subject for indirect object identification. Gendered pronouns and greater-than compare the target token with the source token. The parity model is PT-Large-2L-Aux. The comparison uses different models and edit rules, with layers chosen per task and model.

The SAEBench rows transcribe Table 4 and retain its better-direction arrows. SCR and TPP use a 20-feature ablation budget. Mack et al. caution that those metrics have low signal-to-noise below two billion parameters.
